**Title**
Enemy deaths roll independent, level-gated, rarity-weighted ground drops

**Lens**: SYS

**Status**: active

**Description**
Every enemy death independently rolls a possible card drop and a possible
item drop, each filtered to content the killer's level can use and
weighted toward common rarity, appearing as a transient, visible-to-every
-player ground object that despawns if unclaimed.

**Rationale**
Per the pillar "every drop has value," gear and cards lost to permadeath
must re-enter circulation through a predictable, server-authoritative
supply — not a client-guessable or exploitable one.

**Verification Description**
Reviewed via the SW/CON specs this realizes, each independently verifiable
by test or review.
