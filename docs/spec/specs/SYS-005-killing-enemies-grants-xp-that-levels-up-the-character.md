**Title**
Killing enemies grants XP that levels up the character

**Lens**: SYS

**Status**: active

**Description**
The system capability: every enemy kill grants the killer XP, which
raises their character level (with a visible HP/MP refill and level-up
moment) and permanently raises their account's lifetime XP total,
independent of any future death.

**Rationale**
Per the design pillars, combat needs a moment-to-moment reward loop
distinct from the permanent, death-surviving progression cards and
spirits carry — XP-from-kills is that loop.

**Verification Description**
Reviewed via the SW/CON/ARCH specs this realizes, each independently
verifiable by test or review.
